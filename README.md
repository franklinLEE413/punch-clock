# 下班时间打卡页 v3

## v3 新增
- 打卡后主按钮锁定，避免误触覆盖。
- 修改上班时间只能通过「调整」页完成。
- 支持近 7 日打卡趋势统计。
- 统计近 7 日平均、最早、最晚打卡时间。
- 趋势中标记 08:30 前为偏早、09:30 后为偏晚。
- 保留补录、目标下班时间反推、日历提醒、网页通知功能。
- 自动兼容 v1 / v2 的本机浏览器历史记录。

## 部署
上传到仓库根目录：
- index.html
- manifest.json
- sw.js
- icon.svg

记录保存在当前设备、当前浏览器的 localStorage 中。换设备、清缓存、换浏览器后不会自动同步。
