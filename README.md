# 下班时间打卡页 v2

纯静态页面，可直接部署到 GitHub Pages。

## 新增功能

- 支持修改 / 补录今天的上班打卡时间
- 支持填写目标下班时间，自动反推需要的打卡时间
- 支持生成 `.ics` 日历提醒文件
- 支持网页通知权限申请
- 支持添加到 iOS 主屏幕
- 加入 `sw.js`，可缓存页面，提升主屏幕打开体验

## 使用方式

1. 新建或打开你的 GitHub Pages 仓库
2. 上传以下文件：
   - `index.html`
   - `manifest.json`
   - `sw.js`
   - `icon.svg`
3. 等 GitHub Pages 更新后，用 iPhone Safari 打开页面
4. 分享 → 添加到主屏幕

## 关于 iOS 提醒

这个页面是纯静态 GitHub Pages 页面，所以不能像原生 App 一样直接写入 iOS「提醒事项」。

目前提供三种方式：

1. 页面打开时的网页通知：适合你当天打开页面后一直保留后台。
2. 生成 `.ics` 日历提醒：可以尝试导入系统日历，在下班时间提醒。
3. 如果想真正写入「提醒事项」，建议用 iOS 捷径配合网页复制出的时间手动创建。
